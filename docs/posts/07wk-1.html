2. 이론 정리

\(N\) 명을 받고, 한 사람당 \(P\) 를 받으며, 보험금은 \(S\), 이자율은 \(i\) 라고 하자.

# 이론1 – \(\bar Z = \mathrm{sum}(Z)/N\) 의 분포는 \(N\) 이 크면 정규분포에 가깝다(중심극한정리). 사람마다의 \(Z\) 가 서로 독립이고 분포가 같기 때문이다. 평균과 분산은

\[ \mathrm{E}[\bar Z] = \mathrm{E}[Z], \qquad \mathrm{V}[\bar Z] = \frac{\mathrm{V}[Z]}{N} \]

이라서, \(N\) 이 크면 \(\bar Z \overset{\cdot}{\sim} N\!\left(\mathrm{E}[Z],\ \dfrac{\mathrm{V}[Z]}{N}\right)\) 이다. 한 사람 \(Z\) 의 평균과 분산만 알면 된다.

# 이론2 – \(t\) 시점의 잔고는

\[ \text{balance}(t) = (1+i)^t\,\bigl(NP - S\,\mathrm{sum}_t(Z)\bigr) \]

이다. 여기서 \(\mathrm{sum}_t(Z)\) 는 \(t\) 시점까지 죽은 사람들의 \(Z\) 만 더한 것이다.

# 이론3 – 파산하는 사건은 시점 \(t\) 에 무관하다. 파산은 모두 죽고 정산할 것을 다 한 뒤에 최종으로 판단하기 때문이다. 식으로 보자. 모두 죽은 뒤(= 줄 거 다 준 뒤)에는 \(\mathrm{sum}_t(Z) = \mathrm{sum}(Z)\) 로 굳어 더 변하지 않으므로, 그 뒤 어느 시점 \(t\) 에서 잰 남은 돈은

\[ \text{balance}(t) = (1+i)^t\,\bigl(NP - S\,\mathrm{sum}(Z)\bigr) \]

이다. 파산은 이 남은 돈이 음수인 사건이므로

\[ \begin{aligned} \text{파산} &\iff (1+i)^t\,\bigl(NP - S\,\mathrm{sum}(Z)\bigr) < 0 \\ &\iff NP - S\,\mathrm{sum}(Z) < 0 && (\because (1+i)^t > 0) \\ &\iff S\,\mathrm{sum}(Z) > NP \\ &\iff \frac{\mathrm{sum}(Z)}{N} > \frac{P}{S} && (\because NS > 0) \\ &\iff \bar Z > \frac{P}{S} \end{aligned} \]

이다.

# 이론4 – 모두 죽은 뒤 남은 돈의 분포는 \(\mathrm{sum}(Z)\) 의 분포를 좌우로 뒤집은 모양이다. 이론3 의 남은 돈 식을 \(\mathrm{sum}(Z)\) 에 대해 정리하면

\[ \text{balance}(t) = \underbrace{(1+i)^t NP}_{\text{상수}} - \underbrace{(1+i)^t S}_{\text{양수}}\cdot \mathrm{sum}(Z) \]

이다. \(\mathrm{sum}(Z)\) 에 음수 \(-(1+i)^t S\) 를 곱해서 좌우가 뒤집히고, 상수 \((1+i)^t NP\) 를 더해서 눈금 위치가 달라진다. 분포의 모양은 그대로다.

# 이론5 – 한 사람 \(Z\) 의 평균 \(\mathrm{E}[Z]\) 는 EPV 를 구하는 식 그대로다. 분산은 \(\mathrm{V}[Z] = \mathrm{E}[Z^2] - \mathrm{E}[Z]^2\) 인데, \(Z^2 = (v^T)^2 = (v^2)^T\) 이므로 \(\mathrm{E}[Z^2]\) 는 \(v\) 대신 \(v^2\) 을 넣고 \(\mathrm{E}[Z]\) 를 구하는 것과 같은셈이다. 즉 \(\mathrm{E}[Z]\) 를 구하는 법만 알면 \(\mathrm{E}[Z^2]\) 도 같은 법으로 구할 수 있고, 둘을 빼면 분산이 나온다.

# 이론6 – \(N\) 이 클 때 파산할 확률은 이론1 과 이론3 을 합치면 바로 나온다.

\[ \bar Z \overset{\cdot}{\sim} N\!\left(\mathrm{E}[Z],\ \frac{\mathrm{V}[Z]}{N}\right) \]

이고, 파산은 \(\bar Z > P/S\) 이므로

\[ \Pr[\text{파산}] = \Pr\!\left[\bar Z > \frac{P}{S}\right] \]

을 이 정규분포에서 읽으면 된다.

3. 연습문제

# 예제1 – (이론1) 남은 수명이 확률 \(0.2\) 로 2년, 확률 \(0.8\) 로 30년인 사람들을 서로 독립으로 \(N\) 명 받는다(\(i = 0.05\)). \(\bar Z\) 의 분포를 그렸더니 아래와 같았다. (a)(b)(c) 는 \(N = 1, 5, 50\) 중 하나씩이다.

어느 것이 \(N = 50\) 이라고 생각하는가?

(풀이)

# 예제2 – (이론1) 남은 수명이 확률 \(0.2\) 로 2년, 확률 \(0.8\) 로 30년인 사람들을 서로 독립으로 받는다(\(i = 0.05\)). 한 사람의 \(Z = v^T\) 는 \(\mathrm{sd}[Z] = 0.2703\) 이다. \(\bar Z\) 의 표준편차를 \(0.01\) 이하로 만들려면 몇 명 이상 받아야 하는가?

(풀이)

\(\mathrm{sd}[\bar Z] = 0.2703/\sqrt N \le 0.01\) 이면 \(\sqrt N \ge 27.03\), 곧 \(N \ge 730.6\) 이다. 731명 이상 받아야 한다.

# 예제3 – (이론2) 남은 수명이 확률 \(0.2\) 로 2년, 확률 \(0.8\) 로 30년인 사람 \(N = 3\) 명을 받고, 한 사람당 \(P = 3{,}665\) 만원을 받았다. 보험금은 \(S = 10{,}000\) 만원, \(i = 0.05\) 다. 한 명은 2년에, 두 명은 30년에 죽었다. \(\text{balance}(t)\) 는 아래 (a)(b) 중 어느 것인가?

(풀이)

  1. 다.

# 예제4 – (이론3) 남은 수명이 확률 \(0.2\) 로 2년, 확률 \(0.8\) 로 30년인 사람 \(N = 5\) 명을 서로 독립으로 받고, 한 사람당 \(P = 4{,}000\) 만원을 받았다. 보험금은 \(S = 10{,}000\) 만원, \(i = 0.05\) 다. 다섯 명 중 몇 명 이상이 2년에 죽으면 파산하는가?

(풀이1)

- 받은 돈에 이자가 붙다가, 누가 죽으면 그때 1억(10,000)씩 빠진다로 센다면 아래와 같다.

  • 2년에 1명: \(20{,}000 \xrightarrow{\times 1.05^2} 22{,}050 \xrightarrow{-10{,}000} 12{,}050 \xrightarrow{\times 1.05^{28}} 47{,}238 \xrightarrow{-40{,}000} 7{,}238\)
  • 2년에 2명: \(20{,}000 \xrightarrow{\times 1.05^2} 22{,}050 \xrightarrow{-20{,}000} 2{,}050 \xrightarrow{\times 1.05^{28}} 8{,}036 \xrightarrow{-30{,}000} -21{,}964\)

따라서 2년에 2명이 죽으면 파산한다.

- \(\text{balance}(t) = (1+i)^t\,\bigl(NP - S\,\mathrm{sum}_t(Z)\bigr)\) 이 수식을 이용하여 풀 수도 있다. \(i = 0.05\), \(NP = 5 \times 4{,}000 = 20{,}000\), \(S = 10{,}000\) 을 넣어 두 시점의 잔고를 구하자. (\(1.05^2 = 1.1025\), \(1.05^{30} = 4.3219\), \(v^2 = 0.9070\), \(v^{30} = 0.2314\))

2년에 1명 죽음 2년에 2명 죽음
\(\mathrm{sum}_2(Z)\) \(0.9070\) \(2 \times 0.9070 = 1.8140\)
\(\text{balance}(2)\) \(1.05^2\,(20{,}000 - 9{,}070) \approx 12{,}050\) \(1.05^2\,(20{,}000 - 18{,}140) \approx 2{,}051\)
\(\mathrm{sum}_{30}(Z)\) \(0.9070 + 4 \times 0.2314 = 1.8326\) \(2 \times 0.9070 + 3 \times 0.2314 = 2.5082\)
\(\text{balance}(30)\) \(1.05^{30}\,(20{,}000 - 18{,}326) \approx 7{,}235\) \(1.05^{30}\,(20{,}000 - 25{,}082) \approx -21{,}964\)
파산 아님 파산

- 그래프로 보면 아래와 같다.

(풀이2) – 공식으로 풀이. 파산 \(\iff \bar Z > P/S = 0.4\) 다. (\(v^2 = 0.9070\), \(v^{30} = 0.2314\))

  • 한 명: \(\bar Z = (0.9070 + 4 \times 0.2314)/5 = 0.3665 < 0.4\) — 파산 아님
  • 두 명: \(\bar Z = (2 \times 0.9070 + 3 \times 0.2314)/5 = 0.5016 > 0.4\) — 파산
  • 세 명: \(\bar Z = (3 \times 0.9070 + 2 \times 0.2314)/5 = 0.6368 > 0.4\) — 파산
  • 네 명: \(\bar Z = (4 \times 0.9070 + 0.2314)/5 = 0.7719 > 0.4\) — 파산
  • 다섯 명: \(\bar Z = (5 \times 0.9070)/5 = 0.9070 > 0.4\) — 파산

# 예제5 – (이론4) 남은 수명이 확률 \(0.2\) 로 2년, 확률 \(0.8\) 로 30년인 사람들을 서로 독립으로 \(N = 2\) 명 받고, 한 사람당 EPV 만큼(\(P = 3{,}665\) 만원) 받았다. 보험금은 \(S = 10{,}000\) 만원, \(i = 0.05\) 다. 왼쪽은 \(\mathrm{sum}(Z)\) 의 분포다 — 값은 \(0.46\) (둘 다 30년), \(1.14\) (한 명 2년), \(1.81\) (둘 다 2년) 이고 확률은 \(0.64,\ 0.32,\ 0.04\) 다. 오른쪽 (a)(b)(c) 중 모두 죽은 뒤(\(t = 30\)) 남은 돈의 분포는 어느 것인가?

# 예제6 – (이론6) 20세 \(N\) 명을 서로 독립으로 받는다. 생존함수는

\[ S_{20}(t) = \exp\left\{-\frac{B}{\log c}\,c^{20}\left(c^t - 1\right)\right\}, \qquad B = 0.0003,\ c = 1.07 \]

이고, 보험금은 \(S = 10^8\) 원(1억), \(i = 0.05\) 다. 한 사람의 \(Z = v^{T_{20}}\) 는 \(\mathrm{E}[Z] = 0.1129\), \(\mathrm{V}[Z] = 0.0168\) 이다. 한 사람당 \(P/S = \mathrm{E}[Z] + 0.01\), 곧 EPV 보다 \(100\) 만원 더 받는다고 하자. \(N\) 이 커지면 \(\bar Z\) 의 분포 · 파산할 확률 · 기대수익은 어떻게 변하는가? (풀지 말고 보기만 하세요)

(풀이) \(\bar Z \overset{\cdot}{\sim} N\!\left(0.1129,\ 0.0168/N\right)\) 이고 파산은 \(\bar Z > P/S = 0.1229\) 다. 아래 그림은 \(N\) 을 \(1\) 에서 \(10{,}000\) 까지 키우며 이것을 그린 것이다.
